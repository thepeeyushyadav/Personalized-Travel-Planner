## 🚀 About The Project

The **Personalized Travel Itinerary Planner** is a full-stack, AI-powered web application that simplifies travel planning through intelligent automation and personalized recommendations. Built with a **React frontend**, **FastAPI backend**, and **Supabase** integration, it generates customized **day-by-day itineraries** based on user preferences, budget, and travel style using **prompt engineering** and **Generative AI (Groq/LLaMA3)**.

The system delivers optimized travel plans that include:
- 🏛️ **Attractions** — Time-optimized sightseeing recommendations
- 🍽️ **Dining** — Curated restaurant suggestions matching dietary needs
- 🏨 **Accommodations** — Budget-appropriate hotel/stay options
- 🚌 **Transportation** — Route-optimized daily travel tips

With a modern **SaaS-style dashboard**, smart **trip builder**, and **interactive itinerary view**, the platform **reduces decision fatigue** and saves hours of travel planning time. Users can quickly generate, save, edit, and regenerate trips while receiving curated recommendations tailored to their needs.

## 🎯 Use Case Scenarios

### 🎒 Scenario 1: Solo Traveler Planning a Weekend Getaway
A solo traveler wants to plan a short weekend trip but has limited time to research attractions and routes. They enter their destination, budget, travel dates, and interests such as food and sightseeing into the planner. Within seconds, the system generates a balanced itinerary that optimizes travel time, suggests nearby attractions, and recommends affordable dining spots. The traveler follows a clear, structured plan and avoids spending hours searching across multiple websites — resulting in a smooth and stress-free getaway.

### 💑 Scenario 2: Couple Planning a Personalized Vacation
A couple planning a romantic vacation wants a customized experience rather than generic tourist recommendations. They select preferences like relaxed pacing, scenic spots, and premium stays. The platform uses AI to create a day-wise itinerary including curated restaurants, unique experiences, and optimized travel routes. They can modify activities, regenerate specific days, and track estimated costs — allowing them to collaboratively refine their plan and enjoy a tailored trip that aligns with their expectations.

### 👨‍👩‍👧‍👦 Scenario 3: Small Group Coordinating a Multi-Day Trip
A group of friends organizing a multi-day holiday faces challenges coordinating schedules, budgets, and shared interests. Using the planner's dashboard, they create a shared trip, input group size, and combine preferences such as adventure, culture, and budget limits. The system automatically structures activities, allocates time efficiently, and provides logistics suggestions to minimize conflicts and travel delays.

## 🏁 Getting Started

### Prerequisites

- **Node.js** 18+ → [Download](https://nodejs.org/en/download)
- **Python** 3.10+ → [Download](https://python.org)
- **Supabase** account (free) → [supabase.com](https://supabase.com)
- **Groq API** key (free) → [console.groq.com](https://console.groq.com)

### 1. Clone the Repository

```bash
git clone https://github.com/thepeeyushyadav/Personalized-Travel-Planner.git
cd Personalized-Travel-Planner
```

### 2. Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (Mac/Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Copy and fill environment variables
copy .env.example .env
# Edit .env with your actual keys

# Start the server
uvicorn app.main:app --reload --port 8000
```

Backend runs at: `http://localhost:8000`
API Docs at: `http://localhost:8000/api/docs`

### 3. Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Copy and fill environment variables
copy .env.example .env
# Set VITE_API_URL=http://localhost:8000/api

# Start dev server
npm run dev
```

Frontend runs at: `http://localhost:5173`

### 4. Supabase Database Setup

1. Create a project at [supabase.com](https://supabase.com)
2. Go to **SQL Editor → New Query**
3. Copy all content from [`backend/app/config/schema.sql`](backend/app/config/schema.sql)
4. Click **Run** → You should see: `"Success. No rows returned"`
5. Verify 5 tables are created: `profiles`, `trips`, `itineraries`, `saved_places`, `trip_history`

## 🗄️ Database Schema

```sql
-- 5 Tables with Row Level Security (RLS)
profiles        -- User profile data (linked to Supabase Auth)
trips           -- Trip plans with destination, dates, budget, vibe
itineraries     -- Day-by-day AI-generated plans (per trip)
saved_places    -- User-bookmarked places
trip_history    -- Action logs for trip events
```

Key features:
- ✅ Row Level Security — users can only access their own data
- ✅ Auto-trigger: profile created on user signup
- ✅ Auto-update `updated_at` timestamps
- ✅ Shared trips accessible via public `share_token`

## 🚀 Deployment

### Deploy Backend → Render

1. Go to [render.com](https://render.com) → **New Web Service**
2. Connect your GitHub repository
3. Configure:
   ```
   Root Directory:  backend
   Build Command:   pip install -r requirements.txt
   Start Command:   gunicorn app.main:app -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:$PORT
   ```
4. Add Environment Variables from your `.env` file
5. Click **Deploy** → Wait for "Live" status
6. Copy your Render URL: `https://your-app.onrender.com`

### Deploy Frontend → Vercel

1. Go to [vercel.com](https://vercel.com) → **New Project**
2. Import your GitHub repository
3. Configure:
   ```
   Root Directory:   frontend
   Build Command:    npm run build
   Output Directory: dist
   ```
4. Add Environment Variable:
   ```
   VITE_API_URL = https://your-render-backend.onrender.com/api
   ```
5. Click **Deploy** → Copy your Vercel URL
6. Go back to Render → Add `FRONTEND_URL = https://your-app.vercel.app`
